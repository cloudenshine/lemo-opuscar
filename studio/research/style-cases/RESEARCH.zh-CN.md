## 为什么旧提案不过关

这是对旧稿的创作判断，不冒充用户调研结论：旧稿主要证明“故事能装进风格”，没有充分证明“观众为什么需要它”。不少故事在结尾附加一句道理，但过程缺少发现、紧张、笑点或具体所得。多个风格承担类似的小型温情寓言，风格覆盖数掩盖了内容同质化。没有实际平台作品、评论或事实材料支撑，就无法区分作者自我感动与真实观看价值。

新稿必须能回答：去掉好看的画面之后，它是否还有一个值得追问的问题或值得经历的体验？再反向检查：重新放回这个风格，它是否让这种价值更容易被感受到？两次检查都需要，不允许用漂亮画面替代内容，也不把风格当作随意更换的皮肤。

## 研究到提案的实际流程

1. 对99种风格分别建立研究入口，允许内容与观众跨类别发展。入口是待检验的起点，不把风格永久锁定到某题材。清单见[99项研究入口](RESEARCH-QUEUE.tsv)。
2. 为每项寻找实际作品与相反案例：优先原始发布页；记录作者、发布时间、观察日期、可见指标、推荐/奖项来源、评论取得情况。榜单入选、点赞、编辑评价分别记录，禁止合成虚假的质量评分。
3. 完整观摩有希望的参考作品，写时间码、开场承诺、信息揭示、表演、镜头、声音、最终兑现；原片未看过就留空。抽样评论时记录排序方式、样本量和典型反对意见，不只摘赞美。
4. 对每个风格提出至少三个彼此不同的内容候选。每个候选分别说明观众处境、具体回报、内容推进、媒介必要性、来源及缺口；不强制A情绪/B知识/C猎奇，不重复同一情节换名词。
5. 用户选择或改写内容之后才进入技术方案与关键段落验证。真实材料无法取得则回到同一风格重新选题，不能以假纪录素材偷偷替代。复杂表演以实际画面验证，不凭技术名称承诺。

## 新候选卡应包含什么

| 字段 | 合格要求 |
|---|---|
| 内容与开场承诺 | 具体问题/处境；第一段让人为什么愿意继续。标题不得先宣布尚未证实的结论 |
| 谁可能需要 | 从这个候选推导，有生活任务、兴趣或情绪处境；是待验证假设，不是给整套99项设人群门槛 |
| 看完得到什么 | 可描述的知识、体验、笑点、惊奇、行动帮助、美感或讨论价值；允许多种组合，不要求每片教育观众 |
| 如何兑现 | 至少一个关键证据、发现、冲突或变化，写出结尾具体发生什么；“感受到温暖/引发思考”本身不够 |
| 为什么用该风格 | 说清它如何参与因果、理解或感受；删掉风格仅剩旁白配图时需要重新设计 |
| 现实参照 | 作品级链接、哪种证据支持什么；区分创作方法参考与本片事实来源，不借用别人热度当新题验证 |
| 独立性与可行性 | 与参照相比新增什么；素材、人物、数据、版权、表演是否可得。不能换皮复刻 |
| 失败判断 | 观众可能在哪里误读或失去兴趣；什么证据会使我们放弃这个候选 |
