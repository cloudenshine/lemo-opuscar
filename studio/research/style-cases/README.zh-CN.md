## 最新任务定义

用户明确纠正：目标是**99种风格各制作一个案例**。先把每一种风格作为构思约束，分别提出三个内容候选，共297个；用户选择或修改后，为该风格落地一个案例。不能再先列少数自由选题，再由助手只挑熟悉的几种风格。

本项目的新次序是：固定风格 → 分别研究现实内容与价值证据 → 三个有依据的内容候选 → 用户选择/改写确认 → 该风格原片与规范深读 → 针对内容确定高质量制作方案 → 关键段落验证 → 完整案例。每个候选各自推导相关观众，不预设统一人群。风格不替代故事，技术仍服务内容。三候选不是三部成片，99种不缩减为三种个人风格；可以分批审阅，但不能遗漏总体覆盖。

《空位》保留第四版，第五版未采用。此决定不自动确认它为纸雕灯影的正式案例；是否纳入99案例计划，需要在该项内容确认时明确。

## 构思依据与限制

作者数据为`candidates.json`，逐项撰写，不以一段通用故事自动替换风格名称。依据是已保存的完整适配表、官方元数据和本轮各风格规范的核心段落摘要；**没有在本轮完整观摩99支原片，也没有完成全部规范的逐条制作审计**。

因此这些是待选择的内容提案，不是已验证的导演方案。覆盖校验能证明99×3不漏项，不能证明每个提案都足够好。确认某个候选后，仍须检查完整风格规范、原片实际效果以及媒介动作是否与故事相容。若发现不相容，先回到该项内容修订，不能默默降格成普通动画或改用其他熟悉风格。

## 真实材料与实现条件

新闻、纪实、档案、真实产品拆解、卫星、点云、显微、数据与地图类按各自规范使用可核验且许可合适的材料。题目中的研究问题不是预先确定的结论；本稿尚未替它们找到全部材料，不能编造数据或假装已采访、实拍、测量。材料不足时更换同一风格下的研究对象，重新确认内容。

允许模拟、虚构模型或概念产品的风格，应按规范标明性质，不能把计算图像伪装成实测。需要图像生成的风格先落实角色一致性与资产方案；需要真人表演或高质量角色动画的内容，不默认沿用此前的Canvas关节人物。涉及新增依赖、外部素材、付费工具或拍摄时，在具体制作方案里说明条件。

## 后续每个案例的交付门槛

1. 用户确认内容：主体、目标或问题、关键变化和结尾清楚；保留本次确认意见。
2. 风格审读：记录完整STYLE约束和实际观摩证据；区分原作方法与不可搬用的原故事。
3. 制作方案：列镜头需要、资产来源、绘制/拍摄/三维/合成方法、声音方案与成本，不凭技术名词保证质量。
4. 关键验证：先证明最难的材料、表演或信息关系，再扩展整片；允许技术方案失败重选。
5. 成片验收：观看理解、艺术质量与技术测试分别记录；未看过不能写通过。
6. 本地与GitHub同步：每种风格一个经确认的案例，保留来源、可编辑文件与复现方式。
