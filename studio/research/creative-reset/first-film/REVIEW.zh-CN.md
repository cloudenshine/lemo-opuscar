## 这次真正改变了什么

创作入口从三套风格模板改为人物关系。先比较鱼与墨迹、擦去墙线、主动让座三个故事结构；否决“环境自动开口、主体不承担选择”的鱼方案。先定义意图与行动，再比较六种候选表达。固定上游索引实际包含99种风格，模板`my-style`不计入。逐项适配表覆盖99项，但尚未完成99支官方影片的完整观摩，不能称为已经掌握所有媒介。

选择分层透光感的剪纸侧影，是为了把人物、行李和座位的关系放在同一可读空间。没有直接套用官方纸雕灯影样片结构，也未完整实现其背光、纸厚和投影规范。当前属于自由表达研究。若未来沿用某个官方风格名称交付，必须满足该STYLE全部约束。

## 与原作内核的对照

对原作的依据沿用[重构诊断](../README.zh-CN.md)：官方导演说明、固定媒体关键帧和本地实现。这里不新增“完整有声观摩了原片”的结论，也不给相似度或超越分数。

| 判断维度 | 原作方法给出的要求 | 此次段落的证据 | 仍然不足 |
|---|---|---|---|
| 变化有原因 | 主体承受阻力并行动 | 行李最初占座；双手抓握后才移动；留出位置后才邀请 | 注意到后来者的眼神仍细微；动机是否读懂需观众复述 |
| 形式参与意义 | 媒介变化本身揭示关系 | 同一空间从被占用到可以共享，前后位置可对应 | 剪纸并非不可替代；换成实拍仍成立，尚未形成媒介独有的发现 |
| 镜头引导认知 | 变化的视点应新增含义 | 发现空位问题时缓推；邀请时保持；回应后退回整体 | 只有一个连续侧向空间，尚未发展有层次的视点转换 |
| 表演承担内容 | 等待、犹豫、动作结果可见 | 看见、收包、空位停留、邀请、回应、落座串联 | 重心、手指和表情仍简化，角色个性不足；不得称为复杂表演达标 |
| 声音与画面同源 | 声音组织同一个事件 | 脚步依据实际足部落地帧生成；布料声对应抓握与放稳；等待段减少音符 | 合成材质感粗略，没有完成主观听审，配乐未形成独特记忆点 |
| 结尾改变开头 | 相同对象获得新意义 | 同一长椅由行李占座转为共同等待 | 结尾很直白；“被接纳”的情感是否成立尚未验证 |

**判断**：这次具备可检验的因果段落，值得拿来验证方向；尚不具备宣称“接近原片”或“青出于蓝”的证据。不能因为技术通过就扩成三套皮肤继续累加。

## 实际检查与修正

检查了4.5、7.3、8.5、10.2、11.6、14.7、17.5、21秒关键帧，以及6.5秒起每0.25秒一帧的16格连续动作图。最初手肘外翻、站姿与落座脚位不协调，已调整骨段长度、收身时机和站立髋部高度。抬包曾遮挡脸部，已降低抬升弧度。片名原先淡入后停留不足，现19.8秒开始淡入、20.2秒清晰；阅读检查采样窗口为2.10秒。

数值测试覆盖每帧让座者手臂可达性、固定骨段长度、人物脚部地面边界、包与髋部位移连续性，验证提手和支撑点在搬运阶段被手持续持有。邀请时一只手仍支撑行李。这些是几何与时序检查，不是自然表演评价；没有完整身体碰撞或物理布料模拟。

## 技术交付

- 独立研究片：22.5秒、1920×1080、30fps、675帧，H.264视频与48kHz双声道AAC，音视频均为22.5秒。
- 实测成片响度−13.82 LUFS，真峰值−2.12 dBTP，响度范围10.3 LU。采用研究片独立归一化与延迟补偿限幅，并测量最终AAC；没有修改旧生产母带流程。
- 源码为TypeScript；没有新增依赖，没有修改上游`styles/`或`core/`。
- 研究渲染绕过旧生产模板的24秒限制；工作台版本保持1.7.0，不把研究片包装成第八轮正式版本。
- 已通过：TypeScript检查、9项单元/服务测试、guard（103项＝99官方＋占位模板＋3个人风格）、675帧非空和确定性跳转、浏览器视频播放/跳转、关键帧图片、手机布局、99种风格搜索/类别/6候选过滤与原规范链接。手机筛选框尺寸缺陷已由该浏览器测试复现并修复。
- 历史影片SHA-256复核：21部与已有对照记录一致。观众理解、情绪与专业听审仍未验证。

## 复现

以下命令均在仓库根目录执行，需已有Node 24、FFmpeg和本项目Chromium依赖。

```powershell
node studio/research/style-atlas/build.ts
node studio/research/creative-reset/first-film/build.ts --stills
node studio/research/creative-reset/first-film/build.ts
npm --prefix studio run typecheck
npm --prefix studio test
npm --prefix studio run guard
node studio/tests/content-first.acceptance.ts
```

Windows沙箱可能阻止测试创建目录链接或访问本机回环端口；这类现有项目/HTTP测试需正常本机权限。研究输出目录带所有权标记，遇到已有异主目录拒绝覆盖。

成片位于`films/space-for-two-proof/out/film.mp4`，连续动作图为同目录`action-strip.jpg`，技术记录为`technical.json`与`mastering.json`；均为可从源文件重建的本地产物，不纳入源码提交。适配表覆盖及原STYLE哈希保存在`.studio/style-atlas/coverage.json`。

## 下一步依据

先让观众不看说明观看，再自由描述“发生了什么、谁改变了什么、哪里没看懂”。若依赖说明才能理解，优先重写看见与回应的表演；如果理解但无感，优先改人物处境和选择的代价。只有这些关系成立，才扩大篇幅、细化媒介与声音。完整系列片数、每片风格和时长保持开放。
