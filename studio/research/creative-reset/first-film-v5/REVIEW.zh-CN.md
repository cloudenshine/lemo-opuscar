# 《空位》第五版：人物结构重绘

用户对第四版的直接反馈是：“现在就像皮影戏，几个转动轴在运动。”这说明仅调整动作的先后和速度没有解决根本的造型问题。本轮重建人物表面，保留故事、接触轨迹、32秒长度、镜头切点与声音，便于判断人物结构本身的差别。

[观看第五版与同步对照](http://127.0.0.1:43821/films/space-for-two-v5-review/index.html) · [先行方案](TREATMENT.zh-CN.md) · [第四版记录](../first-film-v4/REVIEW.zh-CN.md)

## 改变了什么

| 原来暴露的结构 | 本轮实际实现 | 仍有的限制 |
|---|---|---|
| 肩到胯是一块近似硬板 | 单独定义骨盆、腰、胸与肩；用连续曲线包裹；吃力时胸部展开、腰部收窄并改变曲率，衣褶跟随压缩 | 不是肌肉、脂肪或布料物理模拟 |
| 手臂、腿是等宽线段在关节处折转 | 袖管和裤管改成肩/肘/腕、髋/膝/踝宽度不同的连续轮廓；弯处圆转，有褶皱和体积明暗 | 内部仍用两段骨长约束；真实透视缩短和肢体扭转不足 |
| 一张侧脸绕颈部旋转 | 带转面的双眼与颊部；俯仰同时影响头部位置、眼眉、鼻与下颌；头部不再整体刚性旋转 | 转面幅度有限，尚不是完整多角度头部模型 |
| 手接近圆点 | 掌根、拇指、指节与张开程度共同改变轮廓；袖口与腕部对齐 | 手指仍是少量程序化曲线，抓握细节可以继续提高 |
| 女方另一只手缺少明确表现 | 补出远侧手臂与休息的手，安排在身体后方绘制，保留近侧手的帮助动作 | 休息手姿态较固定，尚无细腻的次要表演 |

重绘覆盖全片，不在后半段突然换人物。背景、包的位置、世界空间接触点、镜头与声音延续第四版；人物体积明暗是二维渐变与局部色块，不称为三维光照。

## 视觉检查与修正

关键帧检查发现第一轮重绘的袖管根部仍有硬切边、远侧手臂盖住胸前，以及吃力时嘴角误呈微笑。已圆化袖管连接、调整远侧手臂遮挡顺序，并让用力时嘴角收紧。点头也补充了可见的头部下沉，避免重绘后只剩五官小幅移动。

最终检查了吃力、收手和放松关键帧及点头连续图。新旧静态造型已有明确差别，但静态细节丰富不等于连续表演自然。另提供11.8秒同步对照视频：左第四版，右第五版，对齐原片16.7–28.5秒，静音，便于把注意力放在身体表现上。

首次浏览器检查发现对照视频的自定义文件名不在服务静态白名单内。已将其发布为独立对照项目的标准`out/film.mp4`，复用现有公开路由，并增加范围请求与实际播放回归检查；未放宽服务器文件访问范围。

## 复现

仓库根目录运行，完整对照构建需要已生成的第四版`films/space-for-two-v4/out/film.mp4`。没有该文件时先运行第四版的`build.ts`。

```powershell
node studio/research/creative-reset/first-film-v5/build.ts --stills
node studio/research/creative-reset/first-film-v5/build.ts
npm --prefix studio run typecheck
npm --prefix studio test
npm --prefix studio run guard
node studio/tests/character-body.acceptance.ts
node studio/research/style-atlas/build.ts
```

只更新观看页及标准对照路由时，已有本轮完整输出后可运行：

```powershell
node studio/research/creative-reset/first-film-v5/build.ts --review
```

完整片为`films/space-for-two-v5/out/film.mp4`；同步对照原文件为同目录的`character-comparison.mp4`，观看服务副本为`films/space-for-two-v5-comparison/out/film.mp4`。关键帧、连续图及测量JSON仍由构建生成，不提交到源码。没有新增依赖或改动上游风格。

## 判断边界

本轮完成的是人物表面结构与造型的一次实质修改。**不能据此宣布皮影感已经消除，也不能把二维程序形变称为成熟的角色动画。** 躯干转面、全身重心转换和姿态之间的手绘修形仍有限，固定镜头下的轮廓变化不能证明复杂角度也成立。

这次没有重新逐镜研究上游原片，不声称达到原作者的人物表演水准。应以正常速度观看同步对照：如果仍像一套骨架套着更精细的皮肤，就应进一步修改关键姿态和中间形状，而不是继续堆面部装饰、阴影或更多转轴。
