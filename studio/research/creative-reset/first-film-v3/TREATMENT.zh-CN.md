# 《空位》第三版：让帮助的意图可见

用户反馈：前面的让座能理解，后面“共同分担”的想法成立，但现有画面动作不能一眼解读。此次保留让座段落，重做结尾的视觉因果；无对白、无解释字幕。前三版为同一故事的实验，不是三种风格任务。

已选择的结构为：看见吃力 → 掌心提出帮助并等待 → 对视点头接受 → 挪近托底 → 托稳后松手 → 肩膀放松。备选的解说字幕会替动作解释；一句“我帮你”可以作为后续备选，但先验证用户已同意的无对白方案。

| 时间 | 行为与观看重点 | 镜头与声音 |
|---|---|---|
| 0–16.7 | 保留第二版让座与落座的因果 | 原有镜头；不改已被用户理解的部分 |
| 16.7–18.5 | 包前倾下坠一下，持包者重新托稳并保持紧绷；来者视线看向包 | 双人近景保留手、包和脸；布料声提示重新承重 |
| 19.2–20.4 | 来者摊开向上的手掌，停在离包明显有距离的位置 | 仍在双人近景，不触包、不拉包、不用音效代替意图 |
| 20.4–21.3 | 持包者抬头与对方对视，并点头；对方继续等待 | 不切走人脸，让“接受”有独立观看时间 |
| 21.3–23.5 | 来者挪近，手从包底进入并托住 | 手部较近镜头；只在真正承托时给布料声 |
| 23.5–25 | 双方托稳，将包调整到彼此之间 | 接触先于移动，保持对象身份；不表现成夺走物品 |
| 25.1–27 | 原持包者松开提手，手回到腿上，身体回正、肩膀放松 | 回到双人构图；轻微气息声为合成草案，不是对白 |
| 27–32 | 相望、一起等待，最后出现片名 | 同一个包仍由两端托住；让减负后的状态可见 |

不使用成功提示音、说明箭头或“共同分担”字幕。暂不新增艺术风格，仍承认人物造型和纸感的局限。验收重点是观众能否读懂帮助的提出、接受与结果，不以技术检查代替这个判断。

机器检查：提议阶段手离包至少60像素；点头结束前不得托底；托底完成前不得向中间移动；原持包者释放提手时双方底部支撑必须存在；帧间接触和骨段连续；人物关键部位保持在镜头内。正常速度和静音观看的解读仍需用户反馈。
