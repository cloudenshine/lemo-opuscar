## 审看方法与边界

用户明确授权仅发送这三部样片的视频和音轨给Google。使用既有Antigravity CLI/Gemini通道，媒体目录独立，不发送源码、项目文档、账号或凭据。模型先在不知道剧本的情况下复述故事，逐段记录问题；不是把技术测试当观摩。

1. 每支完整原速视频通过原生视频接口读取，评估结构与节奏。
2. 最终AAC音轨一次解码，再连续切成4秒WAV；拼接PCM必须与原解码逐字节相同，保证没有丢失、重复片段或遗漏片尾。独立音频原生读取、盲听转写，不提供预期旁白。
3. 画面连续分为18秒区间，六倍慢放原生读取，补足动作检查；时间按原片换算，不把慢放速度当原片节奏。
4. 检查工具调用记录，确认实际读取了全部文件；结果必须有连续覆盖的叙事时间轴。对疑似转写漏词再做短段盲听，并回到实际视频核实模型指出的错误。

原速视频通常约1帧/秒进入模型；慢放等效约6帧/秒，不能声称真人连续观看、逐帧视觉验收或毫秒级听觉卡点。音频通过独立原生音频输入核实，不把视频接口返回画面当作已经听到声音。没有收集真实观众理解反馈，也没有宣称达到原作者水准。

初版三片共59个连续音频片段、13个慢放片段及3个完整原速文件；修订版每轮为43个连续音频片段、11个慢放片段及3个原速文件。本地证据保留在 `.studio/trio-av/<slug>/`：源文件SHA-256、覆盖计划、原生读取记录、盲听文本与声画意见。原始模型日志不提交GitHub，避免把个人路径和会话元数据公开。

| 运河 | 66–78秒一次显示整条因果链，信息出现与解说脱节 | 降雨、湖水、限行、等待四步顺序点亮；90秒缩至74秒，旁白原速保留 |
| 勇者 | 5–26秒手套/长臂轮廓被盲看模型误读为美工刀，抬箱之后空等 | 缩短伸臂，补护手拇指与指节、用力时的身体变化；压缩失败与观察段的停留 |
| 勇者 | 26–36秒剑突然换到地上；“请勿划伤内件”用勇者头像，像自言自语 | 剑保持随身，增加拔取与归位过渡；警告延后出现并明确标成“箱上贴着” |
| 勇者 | 44–53秒摘下的物体难辨，右臂突然消失，落物音效早于接触 | 重画手套，抓取手随手套移动后退出；松手后加速下落，接触桌面才发闷响 |
| 勇者 | 60–70秒箱盖自行打开、新箱凭空出现、说话人不明、结尾停留过长 | 增加裸手掀盖；用可辨认的小药水瓶替代抽象尖角物；送件人独立头像与推箱的手入画，放箱声跟随停稳；70秒收紧到42秒 |
| 热成像 | 25–38秒旁白要求比较两区，图却几乎全开；关窗时观察者消失 | 只开半扇，敞开区显示室外，玻璃区保留人影；观察者持续存在，光路区分室内与室外 |
| 热成像 | 句间/结尾多处无信息静止 | 72秒收至52秒；仍全程标“实验分镜·非实测”，在审看页折叠，不放入成片交付区 |

动作并非因为“会移动”就自然。复审后的独立复述已能辨认勇者戴手套失败、尝试用剑、脱手套后成功和新的包裹；但细腻表情、手指接触和喜剧停顿仍较简化。运河能复述完整缺水因果，但仍是图解型科普，不能称为完整卫星纪录片。

最终v3复审仍把勇者拉手套的手读成长条工具，并对开箱后的肤色指尖识别不稳定。这不是“表演已通过”；即使部分意见的时间点和姿态判断有误，也不能用测试通过否定造型难读的问题。该片维持表演样片状态。热成像的接触动作仅为实验示意，没有投入更多动画去代替缺失的真实实验。

## 不照单接受模型意见

- 初版模型声称字幕写成“阀门”，实际源字幕与图像为“闸门”。没有凭模型意见引入不必要改字。
- 中间版模型声称第4因果节点未亮，实际导出62秒画面已点亮；又声称热像人影左右举手相反，实际12秒导出显示两者均举画面右侧手。保留正确画面，记录误报。
- 模型把存在的微小动画称为“静止”，有时是遗漏，有时说明变化不足以被感知。对低信息停留进行剪辑；不把每条模型建议都包装成已确认缺陷。
- 模型按4秒音段估计的音效时点不可靠。落物接触由连续画面、动作时间和生成音轨事件共同检查；没有采用模型声称的毫秒精度。

## 旁白核验

两部科普片仍复用此前已授权向Microsoft发送的23句解说，未扩大外发文本范围，未重新加速语音。勇者无旁白，不给它伪造“语音验收通过”。

盲听中出现“他们/它们”“在/再”的同音字转写差异，不能算读音错误。热成像的“实测应比较”“眼睛和这类热像仪”“常见长波红外”在切段处出现漏词疑点：另切短段盲听，并用修订版不同切分位置交叉核对。“这类”和“红外”能从独立音频读取中确认，不依据脚本补齐。未发现需要替换音频的实质读音错误。

`verify-export.ts`将独立转写与23句逐一对应，并校验最终旁白PCM与初次听审文件完全一致、字幕区间容纳完整语音、最终视频哈希对应声画报告；结果输出到各片 `out/speech-verification.json`。同音字按听觉等价比较，书面字幕保持原文。模型转写可错，不宣称真人发音验收。
