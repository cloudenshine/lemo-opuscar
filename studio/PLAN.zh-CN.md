# 云山墨序：二次开发方案

## 目标与交付边界

以 Lemo-Opuscar 上游 `3a7132b` 为基线，在个人 Fork 的独立分支实现本地制片工作台。保留上游 99 种风格及渲染协议，新增「云山墨序 / Cloud & Ink」个人风格、可编辑项目、Windows 部署入口和真实 MP4 验收样片。用户已选择水墨与东方美学；本版视觉选择由开发实现并记录，后续可版本化调整。

## 现状与取舍

- 上游是风格与工具库，不是完整 Web 应用。直接修改官方风格会增加同步冲突，因此扩展集中在 `studio/`、`personal-styles/`。
- 上游安装脚本依赖 POSIX 的 `.venv/bin/python`，Windows 原生需要独立安装脚本；复用已有 Node 24、Python 3.12、FFmpeg，不修改系统配置。
- 主库仅有 Playwright 与 Three.js。服务端采用 Node 标准库，前端使用原生 HTML/CSS/TypeScript，无运行时新增依赖。TypeScript 与 Node 类型仅作为工作台开发检查依赖，安装在 `studio/`，不增加上游根依赖。
- 原始文档采用 CC BY-NC 4.0，并另有自制影片授权；代码采用 MIT。保留原许可和署名，衍生风格注明改动。本地个人创作不等于取得重新销售上游文档的授权，具体范围以根目录 LICENSE 为准。

## 产品闭环

1. 浏览、搜索上游风格，优先显示自己的「云山墨序」。
2. 输入项目名、中文片名与题跋，建立独立项目，保存可编辑内容与制作说明。
3. 浏览器实时预览，播放、暂停、拖动时间轴；同一 `render(t)` 用于离线渲染。
4. 导出 1920×1080 / 24 fps 样片；工作台展示真实任务状态、错误和成片链接。
5. CLI 支持列出风格、创建项目和渲染，便于 Agent 与后续自动化复用。
6. 个人风格记录配色、字体、笔触、声音、禁忌和变化空间；技能提供发现与复用入口。

## 架构

```text
浏览器工作台 / CLI
  └─ 项目服务（校验、独占创建、内容保存、渲染队列）
      ├─ personal-styles/cloud-ink（规范与原始模板）
      ├─ films/<slug>（用户项目，Git 忽略）
      └─ upstream core/render（确定性画面 → FFmpeg）
```

服务只绑定 `127.0.0.1`。写接口校验 Origin 与 JSON 内容类型；静态文件只允许指定资源目录，不暴露 `.git`、密钥或虚拟环境；路径先解码再做根目录与符号链接检查；项目名拒绝路径、Windows 设备名及覆盖已有目录。渲染同时执行一个任务，状态与输出由真实进程驱动，失败可重试。

## 个人风格 v1

- 名称：云山墨序 / Cloud & Ink；slug：`cloud-ink`；技术底子：`ink-wash`。
- 暖宣纸、五阶墨色、朱砂仅用于小印；大面积留白，避免红色标题和装饰性界面叠在画面上。
- 题跋采用本机中文宋体/楷体，不复制或分发系统字体；跨机字形可能不同，部署说明需明确。
- 模板样片《一叶渡晨》：晨雾显山、墨竹生长、叶落成舟、涟漪远去。它是可测试的短片起点；未来 Agent 创作必须重写 treatment，不把改标题等同于新片。
- 24 秒，1080p，24 fps，程序化拨弦与水声，无旁白，无外部付费接口。

## 后续演进（不冒充本版已实现）

后续可增加多镜头编辑、字幕/旁白生成、竖屏重排、外部素材管理和本地任务持久化。当前不增加账号体系、云部署、收费服务、数据库或第三方模型调用。上游同步先 fetch、比较差异、跑检查，再合并；不对个人分支执行自动 hard reset。
